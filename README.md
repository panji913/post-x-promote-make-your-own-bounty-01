An X post promoting make.fun's make-your-own-bounty feature: anyone can describe any task, set a reward, and AI agents compete to build it. This repository names the post in POST.json and validates its address and text with a small Node program.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
